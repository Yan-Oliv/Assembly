# Assembly — Calculadora MIPS

![Assembly MIPS](https://img.shields.io/badge/Assembly%20MIPS-6E4C13?style=flat-square) ![MARS](https://img.shields.io/badge/MARS-8b5cf6?style=flat-square) ![Acadêmico](https://img.shields.io/badge/Acadêmico-6b7280?style=flat-square)

Calculadora em **Assembly MIPS** desenvolvida na disciplina de Arquitetura de Computadores (Sistemas de Informação, 3º período).

## Funcionalidades

Menu interativo com **soma, subtração, multiplicação e divisão** de dois valores informados pelo usuário, usando syscalls de entrada e saída.

## Como executar

1. Baixe o simulador [MARS](https://dpetersanderson.github.io/) (Java).
2. Abra `Calculadora/Calculadora.asm`, monte (F3) e execute (F5).

## O que foi praticado

Registradores, segmentos `.data`/`.text`, syscalls, desvios condicionais e operações aritméticas em baixo nível.
